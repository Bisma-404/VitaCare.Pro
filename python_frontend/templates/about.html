About the Multi-Disease Detection System

A hybrid C++/Python system designed to demonstrate data structures, algorithms, and intelligent health assessment through machine-learning decision trees.

🚀 Key Features

🧠 C++ Decision Tree Engine

Custom C++ implementation exposed to Python via pybind11.

🏥 Multi-Disease Support

Models for Diabetes, Heart Disease, and Breast Cancer.

📷 OCR Report Parsing

Extract medical values from images using Tesseract OCR.

⚡ Fast Predictions

Deterministic, explainable decision-tree results.

🧩 Modular Frontend

Blueprint-based Flask architecture.

🔒 Reliable Engineering

Connection pooling, optimized compute layer.

🔬 How It Works

Decision Tree Algorithm

  • Information Gain for optimal splitting
  • Entropy & Gini impurity computation
  • Recursive threshold-based splitting
  • Stopping conditions (max depth, min samples)

Architecture

  • C++ Backend: decision-tree engine
  • pybind11: C++ ↔ Python bridge
  • Flask Frontend: OCR + web UI
  • HTML/CSS/JS: Responsive UI

Training Process

  • Data preprocessing from CSV datasets
  • Tree building (C++)
  • Hyperparameter tuning
  • Model saved to disk
  • ~75–85% accuracy depending on dataset

💻 Technology Stack

C++ (engine) Python / Flask MySQL pybind11 Tesseract OCR CMake HTML/CSS/JS

📈 Disease Predictions

1. Diabetes

2. Heart Disease

3. Breast Cancer

Local Setup

  1. Install deps: pip install -r requirements.txt
  2. Build C++ core: cmake -S cpp_core -B build
  3. Set MySQL env vars
  4. Run App: python app.py
