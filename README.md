# 🏥 Multi-Disease Detection Support System

A comprehensive health risk assessment system using a **custom-built C++ Decision Tree** algorithm (no ML libraries!) integrated with a Python Flask web interface.

## 🎯 Features

- **Pure C++ Implementation**: Decision tree built from scratch with custom entropy/Gini calculations
- **Three Disease Predictions**: Diabetes, Heart Disease, and Breast Cancer
- **User-Friendly Interface**: Clean Flask web application with intuitive forms
- **Real-Time Predictions**: Fast C++ backend for instant results
- **Educational Focus**: Demonstrates DSA concepts in machine learning

## 📋 System Requirements

- **C++ Compiler**: GCC 7.0+ or Clang 5.0+ (C++17 support)
- **CMake**: 3.12 or higher
- **Python**: 3.8 or higher
- **pip**: For Python package management

## 🚀 Installation & Setup

### Step 1: Clone or Setup Project Structure

```bash
# Create project directory
mkdir multi_disease_ds
cd multi_disease_ds

# Create folder structure
mkdir -p cpp_core/include cpp_core/src cpp_core/tests
mkdir -p python_frontend/webapp/templates python_frontend/utils python_frontend/models
mkdir -p datasets build
```

### Step 2: Place Your Files

1. **Place datasets** in `datasets/` folder:
   - `diabetes.csv`
   - `heart.csv`
   - `breast_cancer.csv`

2. **C++ files** in `cpp_core/`:
   - `include/decision_tree.h`
   - `src/decision_tree.cpp`
   - `src/bindings.cpp`
   - `CMakeLists.txt`

3. **Python files** in `python_frontend/`:
   - `train.py`
   - `utils/mapping.py`
   - `webapp/app.py`
   - `webapp/templates/*.html`
   - `requirements.txt`

4. **Root files**:
   - `CMakeLists.txt`
   - `README.md`

### Step 3: Install Python Dependencies

```bash
cd python_frontend
pip install -r requirements.txt
cd ..
```

### Step 4: Build C++ Module

```bash
# Create build directory
mkdir -p build
cd build

# Configure with CMake
cmake ..

# Build
make

# Install Python module
make install

cd ..
```

**Verify Installation:**
```bash
python3 -c "import cpp_tree; print('✓ C++ module loaded successfully!')"
```

### Step 5: Train Models

Train models for all three diseases:

```bash
cd python_frontend

# Train Diabetes model
python3 train.py --disease diabetes --dataset ../datasets/diabetes.csv --max-depth 8 --criterion entropy

# Train Heart Disease model
python3 train.py --disease heart --dataset ../datasets/heart.csv --max-depth 10 --criterion gini

# Train Breast Cancer model
python3 train.py --disease breast_cancer --dataset ../datasets/breast_cancer.csv --max-depth 6 --criterion entropy
```

**Training Options:**
- `--max-depth`: Maximum tree depth (default: 10)
- `--min-samples`: Minimum samples to split (default: 2)
- `--criterion`: 'entropy' or 'gini' (default: entropy)
- `--output`: Custom output path for model

### Step 6: Run Flask Application

```bash
cd webapp
python3 app.py
```

**Access the application at:** `http://127.0.0.1:5000`

## 🧠 Algorithm Details

### Decision Tree Implementation

**Core Components:**
- **Node Structure**: Binary tree with feature index and threshold
- **Impurity Metrics**: 
  - Entropy: `-Σ(p * log₂(p))`
  - Gini: `1 - Σ(p²)`
- **Split Selection**: Evaluates all features and thresholds
- **Information Gain**: `Parent_Impurity - Weighted_Child_Impurity`

**Stopping Conditions:**
1. All samples have same label
2. Maximum depth reached
3. Minimum samples requirement not met
4. No valid split available

## 🔧 Troubleshooting

### Common Issues

**1. C++ Module Import Error**
```bash
# Check if module was built
ls python_frontend/cpp_tree*.so

# If missing, rebuild:
cd build
make clean
cmake ..
make
make install
```

**2. Model Not Found Error**
```bash
# Check models exist
ls python_frontend/models/

# Retrain if missing
cd python_frontend
python3 train.py --disease [disease_name] --dataset ../datasets/[dataset].csv
```

**3. CMake Configuration Issues**
```bash
# Install pybind11
pip install pybind11

# Find pybind11 config
python3 -m pybind11 --cmakedir

# Add to cmake command:
cmake -Dpybind11_DIR=$(python3 -m pybind11 --cmakedir) ..
```

**4. Flask Import Error**
```bash
# Reinstall Flask
pip install --upgrade Flask
```

## 📝 Usage Examples

### Command Line Prediction
```python
import cpp_tree

# Create model
tree = cpp_tree.DecisionTree()

# Prepare data
data = [cpp_tree.DataPoint([features], label) for features, label in dataset]

# Train
tree.train(data, max_depth=10, min_samples_split=2, criterion="entropy")

# Predict
features = [6, 148, 72, 35, 0, 33.6, 0.627, 50]  # Diabetes features
prediction = tree.predict(features)
print(f"Prediction: {prediction}")  # 0 or 1
```
