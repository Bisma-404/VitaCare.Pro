🏥 Multi-Disease Detection System

Educational AI-Powered Health Risk Assessment Platform

🎯 About This Project

The Multi-Disease Detection System is an educational platform demonstrating the practical application of data structures and algorithms in healthcare AI. This system uses a custom-built C++ Decision Tree algorithm (no external ML libraries) integrated with a Python Flask web interface to predict health risks for three major diseases.

This project showcases the intersection of computer science fundamentals and real-world applications, proving that complex machine learning concepts can be implemented from scratch using core programming principles.

🔬 How It Works

Decision Tree Algorithm

At the core of this system is a binary decision tree that makes predictions by recursively splitting data based on feature values. The algorithm implements:

  • Information Gain: Measures the reduction in entropy when splitting data
  • Entropy Calculation: -Σ(p * log₂(p)) to measure data impurity
  • Gini Impurity: 1 - Σ(p²) as an alternative splitting criterion
  • Recursive Splitting: Finds optimal thresholds for each feature
  • Stopping Conditions: Max depth, min samples, or pure nodes

Architecture

The system uses a hybrid C++/Python architecture for optimal performance and usability:

  • C++ Backend: Core decision tree implementation for speed
  • pybind11: Seamless C++/Python integration without performance loss
  • Python Frontend: Flask web server and OCR processing
  • HTML/CSS/JS: Responsive user interface with modern design

Training Process

Models are trained offline using medical datasets with the following steps:

  • Load and preprocess disease-specific datasets (CSV format)
  • Build decision tree using custom C++ algorithm
  • Optimize hyperparameters (max depth, min samples, criterion)
  • Save trained model to disk for fast loading
  • Achieve 75-85% accuracy depending on dataset and parameters

📈 Disease Predictions

1. Diabetes (8 Features)

Predicts diabetes risk based on: Pregnancies, Glucose Level, Blood Pressure, Skin Thickness, Insulin Level, BMI, Diabetes Pedigree Function, and Age.

2. Heart Disease (13 Features)

Assesses cardiovascular risk using: Age, Sex, Chest Pain Type, Resting BP, Cholesterol, Fasting Blood Sugar, Resting ECG, Max Heart Rate, Exercise Angina, ST Depression, Slope, Major Vessels, and Thalassemia.

3. Breast Cancer (10 Features)

Analyzes cell characteristics including: Mean Radius, Texture, Perimeter, Area, Smoothness, Compactness, Concavity, Concave Points, Symmetry, and Fractal Dimension.
